# Canvas 学习看板

这是一个运行在 Windows 本机的 Canvas 学习看板：读取你自己的 Canvas 课程和作业状态，展示待完成、逾期、已完成、近期优先事项与已结束课程，并支持个人学习清单。

项目源码位于 [`outputs/canvas-dashboard`](outputs/canvas-dashboard)。详细安装与使用方式见其中的 [README](outputs/canvas-dashboard/README.md)。

## 发布说明

这是本地应用，不是已部署的公共网站。它只监听 `127.0.0.1`，Canvas Token 不会写进本仓库、浏览器存储或项目文件。
